# DollFight 街机质感与 UI 设计

## 目标

在当前 Unity 普通场地与教堂版本上，借鉴《街霸 6》的清晰对战信息、街头赛事排版和分层打击演出，完成可直接运行的美术升级。保留现有角色、真实结算的三分钟 KO 规则、动捕播放与全部调试入口。

## 视觉与交互

- 视觉主张：深色混凝土与金属，粉红 P1 / 冰蓝 P2，荧光黄作为重点提示；高对比斜切大字与克制的颗粒笔刷。以场内角色为主体，减小原有整条黑色顶栏。
- 信息组织：两侧角色名、头像、斜切生命条、扣血残影、六段防守槽；中央倒计时；侧边短暂显示真实接触和连击；底部小型控制栏。防守槽仍是现有 guardEnergy，不能虚构 Drive 或必杀系统。
- 演出：READY / FIGHT 的缩放入场、方向性命中碎片与短促闪光、KO 动态斜切字、随后稳定的胜负及重赛操作。所有伤害与连击都来自导出事件。
- 场地：普通场地改为具有层次的夜间工业擂台，加入可见的混凝土纹理、灯带、墙体结构和原创场地标识；角色使用主光、补光与轮廓光，控制白色衣物过曝；教堂保留扫描并优化角色融合。
- 设置：中文为主的清晰行布局，支持音效、震屏、音量与强度；排练工具完整保留。小窗口不溢出，鼠标和快捷键可用。

## 素材与边界

使用 Poly Haven CC0 材质、Google Fonts OFL 字体、Kenney CC0 音效的少量实际所需文件，下载后本地加载，保存许可、来源和哈希。原扫描许可与署名继续保留。不替换既有骨骼/动作数据，不声称加入实时对战。

## 验收

Unity EditMode、两个 Windows 构建、1440×900 / 960×640 / 宽屏实机截图、设置与重赛交互、接触事件和终局一致性。检查日志、实际图片、运行性能并记录结果，不能用浏览器测试代替原生验证。
