# 3DDollFight

3D 视觉课程的双人体感格斗项目。**Motion Lab v0.6** 将我们负责的两部分放在一个可检查的原型中：骨骼处理与动作识别，以及 VRM 皮套与全身动作映射。

## 看效果

Windows 双击 `Start-MotionLab.cmd`，或运行：

```powershell
git lfs pull
uv sync --locked
uv run --locked python tools/fetch_avatar.py
uv run --locked python -m dollfight.server --open
```

打开 <http://127.0.0.1:18943/>。首次拉取 LFS 角色、同步 Python 依赖、下载官方对照样例需要网络；之后本机 CPU 算法与浏览器渲染均可离线运行。无需摄像头、训练服务器或 Unity。端口占用时加 `--port 18944`。

默认显示 **两套校服底模 + 真人组合动作**。新版以许可明确的 pixiv VRM 底模保留身体绑定和 UV，再制作校服、短发/马尾轮廓和独立裙布；角色外观仍是草稿。旧单图生成皮套保留为不合格对照。先打开 [皮套对照页](http://127.0.0.1:18943/avatar-review.html)，并排检查正侧背面、近景与踢腿。组合片段的衔接是算法编辑，双方仍为同一输入的延迟回放。建议按以下顺序验收：

对照页也已接入两份 **Tripo H2.5 原件**：切「希美 / 霙 · 加入 Tripo 原件」，可看正侧背面、面部与材质区别。免费导出没有可用绑定，故本列明确保持静态。生成、重拓扑、骨骼导出限制和文件检查见 [皮套流水线](docs/avatar-pipeline.md)。它们尚不是可替换的正式角色。

1. 点“收架 → 前踢”等段落，用 **0.25×**、暂停和步进观察换招。开关“组合动作自然衔接”保留当前时间，用同一输入对比硬切和姿态/速度衔接；这不代表任意动作都能自然转换。
2. 切换“真人前踢”“下段格挡”“手刀防御”“真人拳击”。拳击有侧身、降低重心的观察段落；不要把片段标题当作识别标签。
3. “皮套试验”可切换新底模、旧生成模型和原始底模。“衣物碰撞与头发惯性”可对照独立衣物求解与固定裙摆。60 Hz 预计算使暂停、拖动、变速可复现；载入时显示计算进度。T-pose 配合“皮套近看”检查脸、肩、裙摆和背面；也支持导入本地内嵌资源的 `.vrm`。
4. 看下方两个玩家视窗：默认全身取景，保留拳脚和反应空间。“严格眼位实验”仍可开启，但需要物理屏幕尺寸、位置和眼位标定。
5. 切到“对战视图”检查距离、攻击窗口、格挡与碰撞。调整距离后重新计算；前摇无伤害，后摇不能马上再出招，前后摇被打有额外惩罚。

**真人动作的参考攻击时序与规则识别结果分别保存、显示。** 原始动捕不经过人为抬肢体再整体旋转；识别器不读取片段名称或参考标签。旧合成对练保留在下拉框中用于逻辑回归，不能作为动作质量的证据。

## 已实现与边界

| 部分 | 当前交付 |
| --- | --- |
| 骨架处理 | 米制坐标、相机适配、标定、置信度门限、One Euro、缺失预测、固定骨长、关节限位 |
| 全身映射 | 独立骨盆/胸腔朝向，保留躯干扭转；肘膝弯曲平面；按腿长缩放、接地与双骨 IK |
| 动作识别 | 基础拳/膝/踢/蹲/侧倾、回旋踢、转身、护架、拨挡与组合规则；提膝候选延迟，防止踢腿前摇误报膝击；踢腿配合摆臂不再算独立出拳 |
| 皮套 | 54 个 humanoid 映射的 VRM 底模；保留身体/脸部 UV、手指、扭转权重；两套校服外观草稿各约 3.9 万面；裙布 896 顶点独立求解，腿部胶囊碰撞；衣发固定步长缓存。旧 Hunyuan 路线留作对照 |
| 动作衔接 | 五个离线连接点：根位置/朝向对齐，邻近姿态与支撑匹配，0.6 s 位置/速度连续衰减，支撑脚 IK；接地权重渐入渐出，结束不强行跳回开头 |
| 交互验证 | 动捕/骨架/模型对照、逐帧、慢放、噪声消融、全身玩家视窗、实际影响伤害与出招的前后摇 |
| Unity 交接 | [UPM 包与导入步骤](unity/README.md)：UniVRM 加载、Humanoid 映射、坐标转换、全局旋转回放、自动创建检查场景 |

浏览器 VRM 路线已可运行。**本机没有 Unity Editor，Unity 包尚未完成 Editor 编译、导入与播放验收。** 不能把 Python/浏览器测试称为 Unity 验证。

仍未完成：Gemini 实机输入、实时双人同步、基于大量真人数据的分类器、自然的任意招式过渡/受击动画、正式角色资产和大招库。这里保留真人全身运动，而非肌肉/动力学仿真。位移放大和对战边界仍可能造成滑步；动作检查视图保留采集根位移，便于直接发现这一问题。P2 是延迟回放，不能当成实时对手。

## 验证与协作

```powershell
uv run --locked pytest -q
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked python tools/check_contracts.py
node apps/motion-lab/tests/run-tests.js
```

Python 3.10.19、uv ≥0.9.17、依赖由 `uv.lock` 固定。Node 22+ 用于投影测试（可选 Tripo CLI 与演示解耦）；启动界面不需要 npm。浏览器依赖、许可证和 SHA-256 在 `apps/motion-lab/vendor/`，公开动捕的原始哈希在每个样本内；VRM 用 [下载清单](data/avatars/sample.json) 固定，10.8 MB 文件保存在忽略目录。
