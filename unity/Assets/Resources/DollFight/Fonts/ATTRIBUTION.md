# DollFight local UI fonts

Downloaded 2026-11-06 from the official Google Fonts repository. Both fonts are
distributed under the SIL Open Font License 1.1. The original license and
copyright notices are included alongside the font files. These files are used
locally; the player makes no font network requests.

Barlow Condensed ExtraBold Italic provides the original DollFight display
typography and stage signage. Rajdhani SemiBold provides timers and numerals.
Chinese UI uses the installed Microsoft YaHei OS font, with Arial as fallback;
neither operating-system font is redistributed with the game.
